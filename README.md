# Store Counter — شمارش ورود/خروج و کیف سبز فروشگاه

برنامه‌ی ویندوزی برای دوربین Hikvision: تعداد ورودی/خروجی، تعداد حاضرین، و تعداد افرادی که **کیف سبز فروشگاه** دارند را می‌شمارد، در SQLite ذخیره می‌کند و یک **پنل مدیریتی فارسی** (زنده + گزارش روزانه/هفتگی/ماهانه با تاریخ شمسی) ارائه می‌دهد.

## ساختار

```
main.py                    نقطه شروع (exe از همین ساخته می‌شود)
store_counter/
  config.py                خواندن/ذخیره config.json
  db.py                    SQLite: events, snapshots, state + گزارش‌ها
  detectors.py             YOLOv8-ONNX (OpenCV DNN) و حالت جایگزین Motion
  engine.py                ردیابی + عبور از خط + تشخیص کیف سبز (HSV)
  pipeline.py              ترد دوربین -> تشخیص -> دیتابیس + پخش MJPEG
  server.py                API و پنل (Flask)
  demo.py                  صحنه شبیه‌سازی‌شده (دمو و تست)
  web/index.html           پنل مدیریتی فارسی (RTL)
tools/export_model.py      تولید models/yolov8n.onnx
tests/test_core.py         تست‌ها
store_counter.spec         تنظیمات PyInstaller
.github/workflows/         ساخت خودکار exe روی GitHub
```

## اجرا برای توسعه

```bash
pip install -r requirements.txt
python main.py            # پنل: http://127.0.0.1:8080  (پیش‌فرض: حالت دمو)
python -m unittest discover -s tests -v
```

برای تشخیص واقعی یک‌بار مدل را بسازید: `pip install ultralytics onnx` و `python tools/export_model.py`

**نکته:** داده‌های حالت دمو فقط در `data/demo.db` (که با هر اجرا پاک می‌شود) ذخیره می‌شوند و هرگز با دیتابیس واقعی `data/counter.db` مخلوط نمی‌شوند. درخواست‌های تغییر تنظیمات پنل فقط با JSON و از همان آدرس پنل پذیرفته می‌شوند (محافظت در برابر CSRF)؛ هنگام باز کردن پنل به شبکه (`host: 0.0.0.0`) حتماً `admin_password` بگذارید.

## ساخت exe

ساخت exe ویندوز باید روی ویندوز انجام شود. دو راه:

1. **GitHub Actions (پیشنهادی):** ریپو را push کنید، در تب Actions گزینه *Build Windows EXE* را Run کنید (یا tag مثل `v1.0.0` بزنید). خروجی `StoreCounter-win64.zip` (شامل exe و مدل) در Artifacts / Releases قرار می‌گیرد.
2. **روی یک سیستم ویندوز:** `build_exe.bat` را اجرا کنید (Python 3.10–3.12) → پوشه `dist\StoreCounter`.

روی سیستم مشتری: zip را باز کنید → `StoreCounter.exe` → مرورگر باز می‌شود. برای اجرای خودکار با ویندوز `install_autostart.bat` را اجرا کنید.

## تنظیم دوربین

آدرس RTSP دوربین‌های Hikvision:

```
rtsp://USER:PASS@CAMERA_IP:554/Streaming/Channels/101    (جریان اصلی)
rtsp://USER:PASS@CAMERA_IP:554/Streaming/Channels/102    (جریان فرعی - سبک‌تر، پیشنهادی)
```

در پنل → تنظیمات، آدرس را وارد و ذخیره کنید. همچنین می‌توان `config.json` (کنار exe) را ویرایش کرد. اگر پسورد ادمین پنل (`admin_password`) را تنظیم کنید و `host` را `0.0.0.0` بگذارید، پنل از شبکه داخلی هم با کاربر `admin` در دسترس است.

### کالیبراسیون (مهم)

- **خط شمارش:** روی تصویر زنده خط زرد را ببینید؛ مختصات A و B را طوری تنظیم کنید که خط، عرض در ورودی را قطع کند. اگر ورود/خروج برعکس شد، «جهت برعکس» را بزنید.
- **کیف سبز:** رنگ سبز واقعی کیف فروشگاه را با چند ورود آزمایشی بسنجید و بازه HSV و «حداقل سهم پیکسل سبز» را تنظیم کنید (کادر سبز روی تصویر یعنی کیف دیده شده).
- **حساسیت:** اگر افراد کم‌شمار شدند، حساسیت را کمتر کنید؛ اگر اشیای دیگر شمرده شدند، بیشتر.

## محدودیت‌ها

- دوربین‌های سقفی/فیش‌آی تصویر از بالا و دارای اعوجاج می‌دهند و مدل عمومی YOLO روی آن‌ها دقت کمتری دارد. حتماً چند ساعت آزمایش میدانی و مقایسه با شمارش دستی انجام دهید؛ در صورت نیاز تصویر دوربین را روی حالت بدون اعوجاج (Dewarp / پانوراما) تنظیم کنید یا مدل را با تصاویر همان دوربین fine-tune کنید.
- شمارنده «حاضرین» از ورودی منهای خروجی محاسبه می‌شود و خطا جمع می‌شود؛ پیش‌فرض هر نیمه‌شب صفر می‌شود و از پنل قابل اصلاح است.
- مجوز: مدل YOLOv8 (Ultralytics) تحت AGPL-3.0 است؛ برای استفاده تجاری در محصول مشتری، مجوز تجاری Ultralytics یا مدل با مجوز آزاد (مثل YOLOX) لازم است.
